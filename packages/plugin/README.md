# DSH Web Control plugin

Prebuilt plugin for DeepSeek Harness 0.2.0-rc.2. Requires your own HTTPS Relay.

[Installation and pairing](https://github.com/liangkw16/dsh-web-control/blob/main/docs/installation.md) · [Compatibility](https://github.com/liangkw16/dsh-web-control/blob/main/docs/compatibility.md) · [Security](https://github.com/liangkw16/dsh-web-control/blob/main/SECURITY.md)

Install the release tarball through the DSH plugin manager. Import your operator-provided private connection configuration once, then use the generated link or QR code. Keep control links and configuration files private.
