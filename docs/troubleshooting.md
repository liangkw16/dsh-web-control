# 排障

## 链接打开但无法连接

先确认 DSH 在运行、插件已启用、电脑未休眠，Relay `/health/ready` 正常。核对导入配置与 `PUBLIC_ORIGIN` 是否完全相同，包含端口。检查反代是否允许 WebSocket Upgrade、云安全组是否开放 HTTPS 端口。前端升级后可刷新页面。

## 新页面接管

同一设备只允许一个控制页面。新页面接替旧页面后，旧页面失去发送权限是预期行为；不要让多个自动刷新页面相互争抢。

## 证书错误

Host 和浏览器都需要正常信任的 HTTPS 证书。IP 地址需对应 IP SAN，证书需要按时续期。不要关闭验证作为解决方案。

## 文件预览或下载被拒绝

确认文件位于当前会话的注册工作区内，使用支持的本地 provider，没有符号链接，且不超过 32 MiB。文件正在被修改时，重新加载并重试。部分格式只能下载，Office 转换不支持。

## 手机上页面没反应

使用普通浏览器新标签打开，避免嵌入式 WebView 限制 Service Worker；确认系统时间、网络、证书均正常。记录浏览器与系统版本，先用独立验收会话复现。

## 锁屏后不可用

检查是否同时进入系统休眠或断网。桌面自动化无法操作锁屏窗口，与 Web Control Host 的连接状态不是一回事。本项目不会主动修改系统电源或锁屏安全设置。

## 提交问题

使用 GitHub Issue 模板，附 DSH/插件/浏览器版本、复现步骤、脱敏错误码。移除控制链接 fragment、注册配置、Cookie、API Key、真实会话内容、用户名路径和服务器地址。安全漏洞请用私密报告，不要公开复现密钥。
