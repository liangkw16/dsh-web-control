# Changelog

## [0.1.0] - 2026-10-12

First public release, based on the deployed compat.11 implementation.

- Native DSH rc.2 Web UI through a finite remote bridge.
- Session streaming, approvals/questions, queue operations and native session/workspace management.
- New browser controller takeover, reconnect and persistent device pairing.
- Scoped uploads, original history diff, original current-file preview and browser download.
- Bounded, version-bound macOS/Linux local file reads; workspace escapes and symlinks refused.
- Prebuilt plugin, self-hosted Relay deployment kit, pinned UI inputs and SHA256 checksums.
- Chinese/English entry documentation, security policy, contribution guide and CI.

Known limitations: DSH 0.2.0-rc.2 only; no Windows/SSH/custom current-file provider; 32 MiB file limit; no Office conversion or active HTML preview; physical-phone cellular acceptance not certified.
